# Declaração de Conclusão — Roteiro de Testes de Caixa-Preta

---

## 🇧🇷 Português

**À Coordenação da Disciplina de Programação Orientada a Objetos**

Prezado(a) Professor(a),

Declaramos para os devidos fins que o **Roteiro de Testes de Caixa-Preta (Black Box Testing)** do projeto **Anime RPG Gacha System** foi devidamente elaborado e concluído.

O documento apresenta **90 casos de teste** que cobrem todas as funcionalidades do sistema, distribuídos da seguinte forma:

- **Testes Válidos:** 61 casos (entradas dentro das regras de negócio)
- **Testes Inválidos:** 11 casos (entradas que violam restrições)
- **Testes de Limite (Boundary):** 18 casos (valores nos limites aceitáveis)

**Áreas testadas:**
1. Criação e gerenciamento do jogador (Player)
2. Sistema de invocação Gacha (Summon — 1x e 10x)
3. Sistema de Pity (Hard Pity no pull 90, Soft Pity no pull 10)
4. Gerenciamento de inventário (capacidade 200, duplicatas)
5. Sistema de constelação (upgrade por duplicatas)
6. Sistema de progressão (Level Up, Enhance, Power Level, Rank)
7. Missões diárias (12 missões com recompensas)
8. Conquistas (15 conquistas desbloqueáveis)
9. Economia de moedas (Gems, Common Currency, Rare Currency)
10. Tipos de entidades (Hero, Support, Antagonist, Weapon, Artifact, Relic)
11. Tratamento de exceções customizadas
12. Comunicação cliente-servidor via TCP Sockets

O documento está disponível no repositório do projeto:
`docs/Roteiro-Testes-Caixa-Preta.md`

Atenciosamente,

**Mamdouh Alsaodi**
Estudante — Ciência da Computação

## 🇸🇦 العربية

**إلى منسق مقرر البرمجة كائنية التوجه**

الأساتذة الكرام،

نفيدكم بأن **دليل اختبار الصندوق الأسود (Black Box Testing)** لمشروع **نظام أنمي RPG جاتشا** قد تم إعداده وإكماله بالكامل.

يحتوي المستند على **90 حالة اختبار** تغطي جميع وظائف النظام، موزعة كالتالي:

- **اختبارات صحيحة:** 61 حالة (مدخلات ضمن قواعد العمل)
- **اختبارات غير صحيحة:** 11 حالة (مدخلات تخالف القيود)
- **اختبارات على الحدود (Boundary):** 18 حالة (قيم على الحدود المقبولة)

**المجالات المختبرة:**
1. إنشاء وإدارة اللاعب (Player)
2. نظام الاستدعاء جاتشا (Summon — فردي و10×)
3. نظام البيتي (Hard Pity عند السحب 90، Soft Pity عند السحب 10)
4. إدارة المخزون (سعة 200، التكرارات)
5. نظام الأبراج (ترقية عبر التكرارات)
6. نظام التقدم (رفع المستوى، التحسين، مستوى القوة، الرتبة)
7. المهام اليومية (12 مهمة مع مكافآت)
8. الإنجازات (15 إنجاز قابل للفتح)
9. اقتصاد العملات (Gems، العملات المشتركة، العملات النادرة)
10. أنواع الكيانات (Hero، Support، Antagonist، Weapon، Artifact، Relic)
11. معالجة الاستثناءات المخصصة
12. اتصال العميل-الخادم عبر TCP Sockets

المستند متاح في مستودع المشروع:
`docs/Roteiro-Testes-Caixa-Preta.md`

مع خالص التحيات،

**ممدوح السعدي**
طالب — علوم الحاسوب
